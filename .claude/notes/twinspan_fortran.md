## 1回の分割の流れ (`CLASS` の 107-200 行)

1. `RECODE` → `WEIGHT` (稀種の重み下げ) → `RA` (対応分析の第1軸) → 固有値を記録
2. `XMAXMI` で軸の最大・最小を取り，**`AXMAX > -AXMIN` となるよう必要なら符号を反転**する
   (長いほうの端を正にする規約)
3. `CRMIN = AXMIN*CRLONG`，`CRMAX = AXMAX*CRLONG`，`CRMID`・`CRHALF` を作る
4. **`POLISH` をちょうど 2 回** (`IREWT = 2`)．毎回そのあと
   `CRMID = (AXMIN+AXMAX)/2`，`CRHALF = 0.5*CRLONG*(AXMAX-AXMIN)` と更新する
5. **分割点は `CRMID`**．`X(I) >= CRMID` が正群，`X(I) <= CRMID` が負群 (159-160, 166-167 行)
6. `CLOSER` で，2つの子のどちらが「兄弟群」に似ているかを見て左右を決める (番号付けの規約)
7. 指標種: `INDSCO` で帯の外の標本だけを数え，`Y(J) = YY(J)/AXPOS - Y(J)/AXNEG`
   (**相対頻度の差**) を作り，`TOPIND` が `FEEBLE = 0.1` で候補を絞る
8. **指標種の個数は 1..NIND を全部試し，誤分類が最小になる個数を選ぶ** (216-225 行)

## `POLISH` の中身 (`twinsub21.f`)

コメントに書いてあるとおり，**2つの序列を作って足す**．

1. 軸の範囲から帯を作る: `CUTMID=(AXMAX+AXMIN)/2`，`CUTHLF=(AXMAX-AXMIN)*0.5*CRCUT`，
   `CUT1=CUTMID-CUTHLF`，`CUT2=CUTMID+CUTHLF`
2. `INDSCO` が **帯の外の標本だけ**で各種の出現を数える (`Y`=負側，`YY`=正側，
   `AXNEG`・`AXPOS` は各群の重み合計)
3. 各種について
   - `PREF = (AYY-AY)/(AYY+AY)` (相対頻度による選好．**ecan の式と同じ**)
   - `FREQ = AYY+AY` を `FRQLIM` で頭打ち
   - **`PREF` を ±`PRLIM`(=0.5) でクリップ**し，`|PREF|<0.001` は 0.001 にする
     (**足切りではなくクリップ**)
   - `COLWGT = CCWT * (FREQ/FRQLIM)^ICWEXP * (|PREF|/PRLIM)^IPREXP`
     → **頻度に比例し，選好の 4 乗に比例する連続重み**
   - `Y(J) = PREF/PRLIM` (−1〜1 に正規化した選好)
4. **序列1**: `Y` を `COLWGT` で重み付けして標本ごとに加算し，行の重みで割る．
   さらに `max|X|` で割って正規化する
5. **序列2**: 種の重みを基本重み `CCWT` だけに戻し，`Y` の**単純平均** (出現種数で割る)
6. **`X = 序列1 + 序列2`**

## `WEIGHT` の重み下げ (`twinsub18.f`)

```
AY = (種の出現の重み合計) / (標本の重み合計)     # 相対頻度
if (AY >= FRQLIM) AY = FRQLIM                     # 0.2 で頭打ち
COLWGT = CCWT * ((AY/FRQLIM)^ICWEXP * (1-CWTMIN) + CWTMIN)
```

**`vegan::downweight()` とは違う**．vegan は「最も多い種に対する比」で決めるが，
原典は**絶対的な相対頻度 0.2 を基準**にし，**下限 0.01** を置く．
いま ecan は vegan 式なので，固有値が 0.005 ほどずれているのはこれが原因の可能性が高い．

## ecan の現状との差 (対応表)

| 段階 | 原典 | ecan の現状 | 差の性質 |
|---|---|---|---|
| 重み下げ | 相対頻度 0.2 基準，下限 0.01 | 最頻値に対する比 (vegan 式) | **式が違う** |
| 軸の向き | 長いほうの端を正にする | 最大 \|得点\| を正にする | 規約 |
| 精密化の回数 | **ちょうど 2 回** | 収束するまで最大 5 回 | 回数 |
| 精密化の中身 | **2つの序列の和** | 選好の加重平均 1 本 | **構造が違う** |
| 選好の扱い | ±0.5 で**クリップ** (全種が寄与) | 1/3 で**足切り** (差異種だけ) | **構造が違う** |
| 種の重み | 頻度 × 選好の 4 乗の連続重み | 差異種を等重み | **構造が違う** |
| 帯 (zone) | 中央帯の標本を頻度計算から**除く** | 全標本を使う | **境界標本の扱い** |
| 分割点 | 研磨後の軸の**範囲の中点** | 重み付き**重心** (0) | **境界標本の扱い** |
| 指標種の個数 | **誤分類が最小になる個数**を選ぶ | 上位 `max_indicators` 個 | 選び方 |

**切り分けで「境界標本の扱い」に差が集中していたことと，帯・分割点の 2 点が対応する**．

## 一致に向けた方針 (段階順．効果が大きく手数が小さいものから)

| 段階 | 内容 | 手数 | 期待 |
|---|---|---|---|
| P1 | **分割点を範囲の中点に**，**`POLISH` を 2 回固定**，**中央帯の標本を頻度計算から除く** | 小 | **大**．境界標本の食い違いが直接効く |
| P2 | 選好を足切りからクリップに変え，**頻度 × 選好^4 の連続重み**を入れる | 中 | 大．精密化の構造がそろう |
| P3 | **`POLISH` を 2 序列の和**にする | 中 | 大．ここまでで序列は原典と同型になる |
| P4 | **`WEIGHT` の式**に合わせる (相対頻度 0.2 基準・下限 0.01) | 小 | 中．固有値の 0.005 のずれが消えるはず |
| P5 | 軸の向きの規約，指標種の個数を誤分類最小で選ぶ | 小 | 小〜中 |
| P6 | `RA` (198 行) を読み，反復回数・収束条件・正規化を突き合わせる | 中 | 未知 |

- **各段階のあとに，既にある比較の枠組み** (dune・varespec・mite で第1分割の一致と ARI) で
  測れるので，**効果を確かめながら進められる**．
- **設計上の判断が要る**: 原典準拠の挙動を**既定にする**のか，
  `twinspan(polish = "hill")` のように**引数で選べる**ようにするのか．
  既定を変えると今の結果が変わるため，先に決めておく．
- 見積りは **P1-P5 で 0.5-1 日**．P6 は読んでみないと分からない．
